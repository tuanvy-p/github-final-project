# Simple Interest Calculator

A lightweight Bash script that calculates simple interest for a given principal, annual interest rate, and time period.

## Formula

Simple interest is calculated using:

**Simple Interest = (Principal × Rate × Time) / 100**

- **Principal**: The initial amount of money.
- **Rate**: Annual interest rate, expressed as a percentage.
- **Time**: Time period in years.

## Requirements

- Bash (available by default on most Linux and macOS systems; on Windows, use Git Bash or WSL).

## Usage

1. Clone or download this repository.
2. Make the script executable:
   ```bash
   chmod +x simple-interest.sh
   ```
3. Run it:
   ```bash
   ./simple-interest.sh
   ```
4. Enter the principal, annual interest rate, and time period when prompted.

The script displays the calculated simple interest and the total amount (principal plus interest).

## Example

For a principal of `1000`, an annual rate of `5`, and a time period of `2` years:

- Simple interest: `100`
- Total amount: `1100`
